# 🚆 SmartRail Sri Lanka

A premium, PWA-certified smart card ticketing system for Sri Lanka Railways.

## 🏗️ Technical Architecture
- **Frontend:** React (Vite) + Tailwind CSS + Framer Motion.
- **Backend:** Node.js (ESM) + Express.
- **Persistence:** Local JSON-based persistent storage.
- **PWA:** Installable on Mobile & Desktop.

## 🚀 Key Features
- **Official 9-Line Network:** Main Line, Coast Line, Northern Line, and more with official KM markers.
- **Live Tracking:** Real-time train status simulation across the network.
- **Admin Dashboard:** Manage users, update route pricing, and simulate RFID hardware taps.
- **Transaction Ledger:** View real journey history and balance top-ups.

## 🛠️ Setup
1. **Backend:**
   ```bash
   cd backend
   npm install
   node server.js
   ```
2. **Frontend:**
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
